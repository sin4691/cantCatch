# VR 터키 아이스크림 프로젝트 게임 디자인 문서

> 코드 제외 · 싱글·멀티플레이 게임 루프 / 규칙 / 판정 구조 정리

이 문서는 VR 터키 아이스크림 프로젝트의 싱글·멀티플레이 기획을 정리한 문서입니다.  
코드 구현 방식, 클래스명, 함수명은 제외하고 게임 규칙과 기능 의도를 중심으로 작성합니다.

---

## 1. 프로젝트 한 줄 개요

플레이어는 터키 아이스크림 상인이 되어 제한 시간 동안 손님에게 아이스크림을 빼앗기지 않으면서, 아이스크림을 줄 듯 말 듯 회피하고 스킬과 QTE에 성공해 최대한 높은 점수를 기록하는 VR 게임입니다.

---

## 2. 싱글 플레이 기본 게임 루프

1. 플레이어는 광장에서 스폰됩니다.
2. 광장에 있는 부스에 들어가 게임 시작을 선택합니다.
3. 게임이 시작되면 총 60초의 제한 시간이 흐르기 시작합니다.
4. 플레이어는 게임 시작 후 15초 안에 막대기에 아이스크림과 콘을 모두 부착해야 합니다.
5. 준비가 끝나면 손님이 아이스크림을 받거나 빼앗으려고 접근합니다.
6. 플레이어는 막대기를 움직이고 스킬을 사용해 손님의 손을 피하면서 점수를 획득합니다.
7. 플레이 도중 게임오버가 되거나 60초 동안 생존하면 해당 게임에서 얻은 점수를 기록합니다.
8. 기록된 점수를 계속 높이는 것이 싱글 플레이의 최종 목표입니다.

총 60초에는 준비 시간이 포함됩니다. 따라서 15초보다 빨리 준비를 끝낼수록 실제로 점수를 획득할 수 있는 시간이 늘어납니다.

---

## 3. 게임 시작 준비 단계

게임 시작 후 플레이어는 다음 준비를 15초 안에 완료해야 합니다.

1. 막대기를 아이스크림 통에 가져가 아이스크림을 부착합니다.
2. 아이스크림콘이 쌓여 있는 통에 막대기를 가져가 콘을 부착합니다.
3. 아이스크림과 콘이 모두 부착되면 준비가 완료되고 손님 상대 단계가 시작됩니다.

15초 안에 준비를 완료하지 못하면 즉시 게임오버입니다.

---

## 4. 핵심 플레이

- 손님의 추적 대상은 아이스크림 자체가 아니라 아이스크림에 붙어 있는 콘입니다.
- 플레이어가 막대기를 두 손으로 잡고 있으며, 막대기에 아이스크림과 콘이 모두 있고, 콘이 손님의 추적 가능 범위 안에 들어오면 손님은 추적 모드로 전환해 콘을 잡으려고 손을 뻗습니다.
- 플레이어가 막대기를 두 손으로 잡고 있지 않거나, 콘이 없거나, 콘이 추적 가능 범위 밖에 있으면 손님은 대기 상태를 유지합니다.
- 손님 상대 단계에서 대기 상태가 연속 5초 이상 지속되면 게임오버됩니다.
- 플레이어는 터키 아이스크림 상인처럼 막대기를 움직여 손님의 손을 회피합니다.
- 손님의 큰 점수 판정 범위 안에 콘을 유지하면 지속적으로 점수를 얻습니다.
- 손님의 작은 그립 판정 범위에 콘이 닿으면 콘 주기 QTE가 시작됩니다.
- 제한 시간이 적게 남을수록 손님의 손과 QTE 바늘이 빨라져 난도가 상승합니다.
- 이후 손님마다 다른 움직임이나 특정 기믹 패턴을 추가할 수 있습니다.

## 5. 플레이어 스킬

플레이어가 사용할 수 있는 스킬은 총 3개입니다.

### 5-1. 180도 회전 스킬

| 항목 | 내용 |
|---|---|
| 입력 | 오른손 컨트롤러 A 버튼 |
| 사용 조건 | 플레이 중 상시 사용 가능 |
| 효과 | 막대기와 막대기에 붙은 아이스크림·콘을 180도 회전시켜 손님의 손을 회피합니다. |
| 쿨타임 | 기본 1초이며 Inspector에서 조절할 수 있습니다. |
| 회전 유지 시간 | 기본 1초이며 쿨타임과 별도로 Inspector에서 조절할 수 있습니다. |

### 5-2. 콘 주기 스킬

| 항목 | 내용 |
|---|---|
| 발동 조건 | 막대기에 붙은 콘이 손님의 작은 그립 콜라이더에 닿으면 자동으로 QTE가 시작됩니다. |
| 준비 시간 | 그립 판정 직후 3초의 준비 시간을 제공합니다. |
| 입력 | 준비 시간이 끝난 뒤 총 3회의 타이밍 판정에서 오른손 컨트롤러 B 버튼을 누릅니다. |
| 성공 조건 | 3회의 판정 중 대성공을 포함해 2회 이상 성공합니다. |
| 성공 결과 | 콘만 손님 손에 주고 아이스크림은 막대기에 남깁니다. 각 판정의 성공 점수를 합산해 획득합니다. |
| 성공 후 상태 | 스킬 성공으로 콘이 없어지면 손님은 대기 상태로 전환되고 대기 시간이 누적됩니다. |
| 이후 흐름 | 콘 통에서 새 콘을 막대기의 아이스크림에 부착하고 추적 가능 범위 안에 넣어 손님을 추적 모드로 복귀시켜야 합니다. |
| 시간 제한 | 콘 재부착 여부와 관계없이 대기 상태가 연속 5초 이상 지속되면 게임오버됩니다. |
| 실패 결과 | 한 번의 QTE에서 두 번째 실패가 발생하면 손님에게 콘과 아이스크림을 함께 빼앗기고 즉시 게임오버됩니다. |

### 5-3. 얼굴에 아이스크림 묻히기 스킬

| 항목 | 내용 |
|---|---|
| 발동 조건 | 아이스크림이 손님의 얼굴 트리거에 닿아 있는 상태여야 합니다. |
| 입력 | 오른손 컨트롤러 검지 Trigger |
| 사용 횟수 | 한 게임당 최대 2회 |
| 효과 | 사용 후 3초 동안 손님의 움직임 속도를 50% 감소시킵니다. |

## 6. 손님 판정 영역

손님에게는 콘 추적을 시작하는 추적 가능 범위, 점수 획득용 큰 원형 콜라이더, 손 그립 판정용 작은 콜라이더가 있습니다.

| 영역 | 크기 | 역할 |
|---|---|---|
| 추적 가능 범위 | 손이 움직일 수 있는 범위 | 아이스크림에 붙은 콘이 범위 안에 들어오면 손님을 추적 모드로 전환합니다. |
| 점수 콜라이더 | 큰 원형 범위 | 막대기에 붙은 콘이 범위 안에 있는 동안 1초당 1점을 지급합니다. |
| 그립 콜라이더 | 손에 위치한 작은 범위 | 막대기에 붙은 콘이 닿는 즉시 콘 주기 QTE를 시작합니다. |
| 얼굴 트리거 | 얼굴에 위치한 범위 | 아이스크림 묻히기 스킬의 사용 가능 여부를 판정합니다. |

점수와 그립 판정은 막대기에 콘이 정상적으로 붙어 있을 때만 유효합니다.

### 6-1. 손님 추적 상태

| 상태 | 전환 조건 | 행동 |
|---|---|---|
| 추적 모드 | 플레이어가 막대기를 두 손으로 잡고 있으며, 막대기에 아이스크림과 콘이 모두 있고, 콘이 추적 가능 범위 안에 있음 | 손님이 콘을 목표로 손을 움직여 잡으려고 하며 누적된 대기 시간이 초기화됩니다. |
| 대기 상태 | 플레이어가 막대기를 두 손으로 잡고 있지 않거나, 콘이 없거나, 콘이 추적 가능 범위 밖에 있음 | 손님이 콘을 추적하지 않고 대기하며 대기 시간이 누적됩니다. |

대기 상태 제한은 손님 상대 단계에서 적용됩니다. 대기 상태가 연속 5초 이상 지속되면 게임오버되며, 5초가 되기 전에 추적 모드로 복귀하면 대기 시간은 0초로 초기화됩니다.

콘 주기 스킬 성공 직후에는 막대기에 아이스크림만 남으므로 손님은 즉시 대기 상태가 됩니다. 플레이어는 막대기를 두 손으로 잡은 상태에서 새 콘을 부착하고, 콘을 추적 가능 범위 안에 넣어 손님을 추적 모드로 전환해야 합니다.

## 7. 싱글 플레이 콘 주기 QTE

콘이 손님의 그립 콜라이더에 닿으면 한 번의 QTE에서 최대 3회의 타이밍 판정을 진행합니다.

1. 그립 판정과 동시에 QTE 진입 상태가 됩니다.
2. 플레이어에게 3초의 준비 시간을 제공합니다.
3. 준비 시간이 끝나면 원형 UI가 표시되고 바늘이 회전하기 시작합니다.
4. 플레이어는 오른손 컨트롤러 B 버튼을 눌러 바늘을 멈춥니다.
5. 바늘이 멈춘 위치에 따라 대성공, 성공, 실패 중 하나를 판정합니다.
6. 두 번째 실패가 발생하지 않았다면 다음 타이밍 판정을 시작합니다.
7. 총 3회의 판정이 끝났을 때 성공 횟수가 2회 이상이면 콘 주기 스킬에 성공합니다.

대성공은 성공 횟수 1회로 계산합니다. 두 번째 실패가 발생하면 남은 기회가 있더라도 즉시 QTE를 종료하고 게임오버 처리합니다.

| 판정 | 원형 UI 구간 | 성공 횟수 | 점수 |
|---|---|---|---|
| 대성공 | 성공 판정 구간 앞부분의 좁은 영역 | 성공 1회 | 20점 |
| 성공 | 대성공 영역을 제외한 일반 성공 영역 | 성공 1회 | 10점 |
| 실패 | 성공 영역 밖 | 실패 1회 | 0점 |

### 7-1. QTE 결과와 점수 예시

각 성공 점수는 판정 즉시 누적됩니다. 따라서 최종적으로 게임오버되더라도 그 전에 획득한 성공 점수는 유지됩니다.

| 3회 판정 결과 | 추가 점수 | 최종 결과 |
|---|---|---|
| 성공 + 성공 + 성공 | 30점 | 콘 주기 스킬 성공 |
| 성공 + 성공 + 대성공 | 40점 | 콘 주기 스킬 성공 |
| 성공 + 성공 + 실패 | 20점 | 콘 주기 스킬 성공 |
| 성공 + 대성공 + 실패 | 30점 | 콘 주기 스킬 성공 |
| 성공 + 실패 + 실패 | 10점 | 두 번째 실패 시 게임오버 |
| 대성공 + 실패 + 실패 | 20점 | 두 번째 실패 시 게임오버 |
| 실패 + 실패 | 0점 | 두 번째 판정 직후 게임오버, 세 번째 판정 미진행 |

위 표에 없는 조합도 일반 성공 10점, 대성공 20점을 합산하고 실패가 2회인지에 따라 같은 규칙으로 처리합니다.

QTE 바늘의 회전 속도는 60초 제한 시간 중 남은 시간이 적을수록 빨라집니다.
QTE가 진행되는 동안에는 60초 게임 타이머가 정지하며, QTE가 종료되면 기존 남은 시간부터 다시 흐릅니다.

## 8. 점수 규칙

| 점수 종류 | 획득 조건 | 획득 점수 |
|---|---|---|
| 지속 점수 | 막대기에 붙은 콘이 손님의 큰 점수 콜라이더 안에 있음 | 1초당 1점 |
| QTE 개별 성공 | 각 타이밍 판정에서 바늘이 일반 성공 영역에 정지 | 판정당 10점 |
| QTE 개별 대성공 | 각 타이밍 판정에서 바늘이 대성공 영역에 정지 | 판정당 20점 |

게임오버가 되더라도 게임오버 시점까지 획득한 점수는 해당 플레이 기록으로 저장합니다.

## 9. 난이도 상승 규칙

- 제한 시간이 적게 남을수록 손님의 손 이동 속도가 빨라집니다.
- 제한 시간이 적게 남을수록 QTE 바늘의 회전 속도가 빨라집니다.
- 손님에게는 추후 개별 기믹 패턴을 추가할 수 있습니다.
- 기믹 패턴은 기본 회피, 점수 획득, QTE 규칙을 해치지 않는 범위에서 확장합니다.

---

## 10. 싱글 플레이 게임오버와 게임 종료

다음 조건 중 하나를 만족하면 게임오버입니다.

- 게임 시작 후 15초 안에 아이스크림과 콘 준비를 완료하지 못한 경우
- 손님 상대 단계에서 대기 상태가 연속 5초 이상 지속된 경우
- 한 번의 콘 주기 QTE에서 두 번째 실패가 발생해 콘과 아이스크림을 함께 빼앗긴 경우

60초 제한 시간이 끝날 때까지 아이스크림을 빼앗기지 않고 생존하면 게임 클리어입니다. 게임오버와 생존 종료 모두 최종 점수를 기록합니다.

---

## 11. 현재 우선 구현 범위

- 광장 스폰과 부스 게임 시작 상호작용
- 60초 게임 타이머와 15초 준비 제한
- 아이스크림 통과 콘 통을 이용한 준비 과정
- 막대기 두 손 그립 여부, 콘 존재 여부, 추적 가능 범위에 따른 손님의 추적 모드·대기 상태 전환
- 대기 상태의 연속 5초 제한, 추적 복귀 시 시간 초기화 및 실패 처리
- 손님의 점수 콜라이더, 그립 콜라이더, 얼굴 트리거
- 1초당 1점의 지속 점수
- 3초 준비 시간과 원형 UI를 사용하는 3회 판정 방식의 콘 주기 QTE
- QTE 일반 성공, 대성공, 실패 횟수 및 누적 점수 판정
- 두 번째 QTE 실패 시 즉시 게임오버 처리
- 180도 회전 스킬, 기본 1초 쿨타임과 별도 회전 유지 시간
- 얼굴에 아이스크림 묻히기 스킬의 2회 제한과 감속 효과
- 남은 시간에 따른 손 속도와 QTE 속도 상승
- 게임오버, 생존 종료, 최종 점수 기록

## 12. 공통 게임 시작 방식

싱글플레이와 멀티플레이 모두 터키 아이스크림 부스에서 시작합니다.

1. 플레이어 한 명이 터키 아이스크림 부스에 들어갑니다.
2. 게임 시작 메뉴에서 싱글플레이 또는 멀티플레이를 선택합니다.
3. 싱글플레이를 선택하면 해당 플레이어가 터키 아이스크림 상인이 되어 게임을 시작합니다.
4. 멀티플레이를 선택하면 손님 대기 칸이 활성화됩니다.
5. 다른 플레이어 한 명이 손님 대기 칸에 들어가 상호작용하면 멀티플레이 참가가 확정됩니다.

---

## 13. 멀티플레이 기본 규칙

- 하나의 월드에는 여러 플레이어가 동시에 접속할 수 있습니다.
- 실제 게임은 두 명의 플레이어가 참여하는 1대1 방식으로 진행합니다.
- 게임에 참가하지 않은 플레이어는 부스 밖에서 대기하거나 진행 중인 게임을 구경할 수 있습니다.
- 참가자 두 명 중 첫 라운드의 터키 아이스크림 상인과 손님 역할은 무작위로 배정합니다.
- 첫 라운드가 끝나면 두 플레이어가 역할을 서로 바꾸어 두 번째 라운드를 진행합니다.
- 각 플레이어는 터키 아이스크림 상인 역할을 한 번씩 플레이합니다.
- 두 라운드가 끝나면 각 플레이어가 터키 아이스크림 상인 역할로 획득한 점수를 비교해 승패를 결정합니다.
- 점수가 높은 플레이어가 승리하며, 점수가 같으면 무승부입니다.

별도로 명시되지 않은 준비 시간, 플레이 제한 시간, 점수 획득 및 스킬 규칙은 싱글플레이의 터키 아이스크림 상인 규칙을 따릅니다.

### 13-1. 멀티플레이 진행 순서

1. 첫 번째 플레이어가 부스의 게임 시작 메뉴에서 멀티플레이를 선택합니다.
2. 손님 대기 칸이 활성화됩니다.
3. 두 번째 플레이어가 손님 대기 칸에 들어가 상호작용합니다.
4. 두 플레이어의 첫 라운드 역할을 무작위로 배정합니다.
5. 첫 번째 라운드를 진행하고 터키 아이스크림 상인의 점수를 기록합니다.
6. 두 플레이어의 역할을 교대합니다.
7. 두 번째 라운드를 진행하고 터키 아이스크림 상인의 점수를 기록합니다.
8. 두 점수를 비교해 승리, 패배 또는 무승부 결과를 표시합니다.

## 14. 멀티플레이 콘 쟁탈 QTE

멀티플레이에서 손님은 직접 콘을 잡아 터키 아이스크림 상인에게 QTE를 발생시킬 수 있습니다.

### 14-1. 시작 조건

1. 손님 플레이어가 오른손 컨트롤러를 아이스크림에 붙은 콘에 닿게 합니다.
2. 콘에 닿은 상태에서 오른손 컨트롤러의 Grip 버튼을 누릅니다.
3. 조건이 충족되면 터키 아이스크림 상인 플레이어에게 QTE가 시작되고, 동시에 손님 플레이어의 연타 입력도 활성화됩니다.
4. 멀티플레이 콘 쟁탈 QTE의 제한 시간은 10초입니다.

### 14-2. 플레이어별 입력

| 역할 | 입력과 목표 |
|---|---|
| 터키 아이스크림 상인 | 기존 원형 QTE UI에서 성공 구간에 맞춰 오른손 컨트롤러 B 버튼을 입력합니다. |
| 손님 | 오른손 컨트롤러 A 버튼을 총 30회 연타합니다. |

### 14-3. 결과 판정

| 결과 | 조건 | 처리 |
|---|---|---|
| 상인 성공 | 손님이 A 버튼 30회 연타를 완료하기 전에 상인이 QTE에 성공 | 콘 주기 스킬이 성공하고 콘만 손님에게 전달됩니다. |
| 손님 성공 | 상인이 QTE에 성공하기 전에 손님이 A 버튼 30회 연타를 완료 | 손님이 콘과 아이스크림을 동시에 빼앗습니다. 해당 상인 라운드는 종료됩니다. |
| 시간 초과 | 10초 안에 상인의 QTE 성공과 손님의 30회 연타 성공이 모두 발생하지 않음 | 아무 일 없이 QTE를 종료하고 일반 플레이로 복귀합니다. |

멀티플레이 콘 쟁탈 QTE는 먼저 성공 조건을 달성한 플레이어의 결과를 즉시 적용합니다. 한쪽의 성공 결과가 확정된 뒤에는 상대 입력을 받지 않습니다.

## 15. 구현 우선순위

멀티플레이는 후순위 구현 대상으로 둡니다. 우선 싱글플레이의 전체 게임 루프, 판정, 점수, 스킬과 게임 종료가 안정적으로 동작하도록 구현한 뒤 멀티플레이를 개발합니다.

멀티플레이 구현 범위는 다음과 같습니다.

- 월드 내 다중 접속과 관전
- 멀티플레이 참가자 두 명 확정
- 첫 라운드 역할 무작위 배정과 두 번째 라운드 역할 교대
- 각 플레이어의 상인 점수 기록과 승패 판정
- 손님 플레이어의 콘 접촉 및 Grip 입력 판정
- 상인의 QTE와 손님의 A 버튼 30회 연타 경쟁
- 10초 제한과 성공 우선 판정

## 16. 기획상 핵심 문장

플레이어는 60초 동안 터키 아이스크림 상인이 되어 손님에게 아이스크림을 빼앗기지 않도록 회피하고, 위험한 거리에서 점수를 쌓으며 QTE와 스킬을 활용해 최고 기록에 도전합니다.
