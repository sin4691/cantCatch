# VR 터키 아이스크림 프로젝트 게임 디자인 문서

> 코드 제외 · 싱글·멀티플레이 게임 루프 / 규칙 / 판정 구조 정리

이 문서는 VR 터키 아이스크림 프로젝트의 싱글·멀티플레이 기획을 정리한 문서입니다.  
코드 구현 방식, 클래스명, 함수명은 제외하고 게임 규칙과 기능 의도를 중심으로 작성합니다.

---

## 1. 프로젝트 한 줄 개요

플레이어는 터키 아이스크림 상인이 되어 제한 시간 동안 손님에게 아이스크림을 빼앗기지 않으면서, 콘을 줄 듯 말 듯 회피하고 스킬과 A 연타 힘겨루기 QTE에 성공해 최대한 높은 점수를 기록하는 VR 게임입니다.

---

## 2. 싱글 플레이 기본 게임 루프

1. 플레이어는 광장에서 스폰됩니다.
2. 광장에 있는 부스에 들어가 게임 시작을 선택합니다.
3. 게임이 시작되면 총 60초의 제한 시간이 흐르기 시작합니다.
4. 플레이어는 게임 시작 후 15초 안에 막대기에 아이스크림과 콘을 모두 부착해야 합니다.
5. 준비가 끝나면 막대기에 붙은 콘이 자동으로 손님의 추적 가능 범위 안으로 이동합니다.
6. 손님은 콘을 추적하고, 플레이어는 막대기를 움직이고 스킬을 사용해 손님의 손을 피하면서 점수를 획득합니다.
7. 플레이 도중 준비 실패로 게임오버가 되거나 60초 동안 생존하면 해당 게임에서 얻은 점수를 기록합니다.
8. 기록된 점수를 계속 높이는 것이 싱글 플레이의 최종 목표입니다.

총 60초에는 준비 시간이 포함됩니다. 따라서 15초보다 빨리 준비를 끝낼수록 실제로 점수를 획득할 수 있는 시간이 늘어납니다.

---

## 3. 게임 시작 준비 단계

게임 시작 후 플레이어는 다음 준비를 15초 안에 완료해야 합니다.

1. 막대기를 아이스크림 통에 가져가 아이스크림을 부착합니다.
2. 아이스크림콘이 쌓여 있는 통에 막대기를 가져가 콘을 부착합니다.
3. 아이스크림과 콘이 모두 부착되면 준비가 완료되고 손님 상대 단계가 시작됩니다.

15초 안에 준비를 완료하지 못하면 즉시 게임오버입니다.

---

## 4. 핵심 플레이

- 손님의 추적 대상은 아이스크림 자체가 아니라 아이스크림에 붙어 있는 콘입니다.
- 막대기에 아이스크림과 콘이 모두 부착되면 콘은 손님의 추적 가능 범위 안으로 자동 이동합니다.
- 콘이 손님의 추적 가능 범위 안에 있으면 손님은 추적 모드로 전환해 콘을 잡으려고 손을 뻗습니다.
- 콘이 없거나 콘이 추적 가능 범위 밖에 있으면 손님은 대기 상태를 유지합니다.
- 플레이어는 터키 아이스크림 상인처럼 막대기를 움직여 손님의 손을 회피합니다.
- 손님의 큰 점수 판정 범위 안에 콘을 유지하면 지속적으로 점수를 얻습니다.
- 손님의 작은 손 콜라이더가 콘 콜라이더에 닿은 상태에서 손님이 Grab 버튼을 누르면 콘 주기 QTE가 시작됩니다.
- 콘 주기 QTE는 상인과 손님이 5초 동안 똑같이 A 버튼을 연타하는 힘겨루기입니다.
- QTE에서 상인이 이기면 10점을 얻고 손님은 화내며 콘을 던집니다.
- QTE에서 손님이 이기면 손님은 콘을 부수고 상인은 게임오버가 아니라 10점을 잃습니다.
- 5초 종료 시점의 판정값이 같아 무승부가 나면 아무 결과 없이 일반 플레이로 돌아가며, 이 경우에만 콘이 막대기에 그대로 붙어 있습니다.
- 손님이 콘을 잡아 QTE를 시작한 누적 횟수가 많아질수록 QTE 시작 지점은 손님에게 점점 유리한 상태가 됩니다.
- 상인 승리나 손님 승리로 콘이 사라진 뒤에는 콘 통에서 새 콘을 다시 부착해야 합니다. 이때 콘 통이 추적 가능 범위 밖에 있어도, 막대기에 콘이 부착되는 순간 붙어 있는 콘은 자동으로 손님의 추적 가능 범위 안으로 끌려옵니다.
- 이후 손님마다 다른 움직임이나 특정 기믹 패턴을 추가할 수 있습니다.

## 5. 플레이어 스킬

플레이어가 사용할 수 있는 스킬은 총 3개입니다.

### 5-1. 180도 회전 스킬

| 항목 | 내용 |
|---|---|
| 입력 | 오른손 컨트롤러 A 버튼 |
| 사용 조건 | 플레이 중 상시 사용 가능 |
| 효과 | 막대기와 막대기에 붙은 아이스크림·콘을 180도 회전시켜 손님의 손을 회피합니다. |
| 쿨타임 | 기본 1초이며 Inspector에서 조절할 수 있습니다. |
| 회전 유지 시간 | 기본 1초이며 쿨타임과 별도로 Inspector에서 조절할 수 있습니다. |

### 5-2. 콘 주기 스킬

| 항목 | 내용 |
|---|---|
| 발동 조건 | 손님의 작은 손 콜라이더가 막대기에 붙은 콘 콜라이더에 닿아 있고, 손님이 Grab 버튼을 누르면 QTE가 시작됩니다. |
| 제한 시간 | QTE는 싱글플레이와 멀티플레이 모두 5초 고정입니다. |
| 입력 | 상인과 손님 모두 5초 동안 A 버튼을 연타합니다. 싱글플레이에서는 컴퓨터가 손님 역할의 A 연타를 수행하고, 멀티플레이에서는 손님 플레이어가 직접 A 버튼을 연타합니다. |
| 상인 성공 조건 | 5초 종료 시점에 상인의 판정값이 손님보다 많습니다. |
| 손님 성공 조건 | 5초 종료 시점에 손님의 판정값이 상인보다 많습니다. |
| 손님 시작 보정 | 손님이 콘을 잡아 QTE를 시작한 누적 횟수가 많을수록 QTE 시작 시 손님 쪽 판정값에 보정이 붙습니다. |
| 무승부 조건 | 5초 종료 시점에 보정값을 포함한 상인과 손님의 판정값이 같으면 무승부입니다. |
| 상인 성공 결과 | 상인이 10점을 얻고, 손님은 화내며 콘을 던집니다. 이후 막대기에는 콘이 없어집니다. |
| 손님 성공 결과 | 손님이 콘을 부수고, 상인은 게임오버가 아니라 10점을 잃습니다. 이후 막대기에는 콘이 없어집니다. |
| 무승부 결과 | 상인과 손님 모두에게 아무 결과를 적용하지 않고 일반 플레이로 복귀합니다. 이 경우에만 콘이 막대기에 그대로 붙어 있습니다. |
| 이후 흐름 | 상인 승리나 손님 승리로 콘이 사라지면 콘 통에서 새 콘을 다시 부착해야 합니다. 콘 통이 추적 가능 범위 밖에 있어도, 막대기에 콘이 부착되는 순간 붙어 있는 콘은 자동으로 손님의 추적 가능 범위 안으로 끌려옵니다. |

### 5-3. 얼굴에 아이스크림 묻히기 스킬

| 항목 | 내용 |
|---|---|

| 입력 | 오른손 컨트롤러 검지 Trigger |
| 사용 횟수 | 한 게임당 최대 2회 |
| 효과 | 사용 후 3초 동안 손님의 움직임 속도를 50% 감소시킵니다. |

## 6. 손님 판정 영역

손님에게는 콘 추적을 시작하는 추적 가능 범위, 점수 획득용 큰 원형 콜라이더, 손에 붙은 작은 손 콜라이더가 있습니다.

| 영역 | 크기 | 역할 |
|---|---|---|
| 추적 가능 범위 | 손이 움직일 수 있는 범위 | 아이스크림에 붙은 콘이 범위 안에 들어오면 손님을 추적 모드로 전환합니다. |
| 점수 콜라이더 | 큰 원형 범위 | 막대기에 붙은 콘이 범위 안에 있는 동안 1초당 1점을 지급합니다. |
| 손 콜라이더 | 손에 위치한 작은 범위 | 막대기에 붙은 콘과 닿아 있고 손님이 Grab 버튼을 누르면 콘 주기 QTE를 시작합니다. |
| 얼굴 트리거 | 얼굴에 위치한 범위 | 아이스크림 묻히기 스킬의 사용 가능 여부를 판정합니다. |

점수와 손 콜라이더 판정은 막대기에 콘이 정상적으로 붙어 있을 때만 유효합니다.

### 6-1. 손님 추적 상태

| 상태 | 전환 조건 | 행동 |
|---|---|---|
| 추적 모드 | 막대기에 아이스크림과 콘이 모두 있고, 콘이 추적 가능 범위 안에 있음 | 손님이 콘을 목표로 손을 움직여 잡으려고 합니다. |
| 대기 상태 | 콘이 없거나 콘이 추적 가능 범위 밖에 있음 | 손님이 콘을 추적하지 않고 대기합니다. |

손님이 Grab 버튼을 누른 뒤에는 0.5초 쿨타임이 적용됩니다. 상인은 이 쿨타임과 180도 회전 스킬을 이용해 손님의 Grab 타이밍을 빼앗고 QTE 진입을 방해할 수 있습니다.

상인 승리나 손님 승리 직후에는 막대기에 아이스크림만 남으므로 손님은 즉시 대기 상태가 됩니다. 플레이어가 콘 통에서 새 콘을 막대기에 부착하면, 부착된 콘은 자동으로 손님의 추적 가능 범위 안으로 이동하고 손님은 추적 모드로 복귀합니다.

## 7. 싱글 플레이 콘 주기 QTE

손님의 작은 손 콜라이더가 콘 콜라이더에 닿은 상태에서 손님이 Grab 버튼을 누르면 5초 고정 시간의 QTE가 시작됩니다. QTE는 상인과 손님이 같은 시간 동안 A 버튼을 연타해 횟수를 겨루는 힘겨루기 미니게임입니다. 싱글플레이에서는 컴퓨터가 손님 역할의 A 버튼 연타를 수행합니다.

1. 손님의 작은 손 콜라이더가 콘 콜라이더에 닿습니다.
2. 손님이 Grab 버튼을 누릅니다.
3. 손님의 Grab 쿨타임 0.5초가 시작되고 QTE 진입 상태가 됩니다.
4. QTE 제한 시간 5초가 시작됩니다.
5. 손님이 콘을 잡아 QTE를 시작한 누적 횟수에 따라 손님 쪽 판정값에 시작 보정을 적용합니다.
6. 상인과 손님은 같은 5초 동안 A 버튼을 연타합니다.
7. 5초 종료 시점에 상인의 판정값이 더 많으면 상인 승리로 처리합니다.
8. 5초 종료 시점에 손님의 판정값이 더 많으면 손님 승리로 처리합니다.
9. 5초 종료 시점에 보정값을 포함한 판정값이 같으면 무승부로 처리합니다.

상인 승리 시 상인은 10점을 얻고 손님은 화내며 콘을 던집니다. 손님 승리 시 손님은 콘을 부수고 상인은 게임오버가 아니라 10점을 잃습니다. 무승부 시에는 아무 결과 없이 일반 플레이로 복귀하며, 이 경우에만 콘이 막대기에 그대로 붙어 있습니다.

상인 승리나 손님 승리로 콘이 사라진 뒤에는 콘 통에서 새 콘을 다시 부착해야 합니다. 콘 통이 추적 가능 범위 밖에 있어도, 막대기에 콘이 부착되는 순간 붙어 있는 콘은 자동으로 손님의 추적 가능 범위 안으로 끌려옵니다.

### 7-1. 손님 시작 보정

QTE는 기본적으로 상인과 손님이 같은 시간 동안 A 버튼을 연타하는 힘겨루기이지만, 매번 50대50 상태에서 시작하지 않습니다. 손님이 콘을 잡아 QTE를 시작한 누적 횟수가 많아질수록 QTE 시작 지점은 손님에게 점점 유리해집니다.

손님 시작 보정은 한 게임 안에서 누적됩니다. 손님이 콘을 잡아 QTE를 시작할 때마다 손님 콘 잡기 누적 횟수를 1 증가시키고, 다음 QTE부터 해당 누적 횟수에 비례한 보정값을 손님 쪽 판정값에 더합니다.

이 보정은 손님이 이미 힘겨루기에서 앞선 상태로 시작하는 기울어진 운동장을 만들기 위한 규칙입니다. 상인은 QTE가 자주 발생할수록 더 빠르게 연타해야 하며, 180도 회전 스킬과 회피로 손님이 콘을 잡는 횟수 자체를 줄이는 것이 중요합니다.

### 7-2. QTE 결과 판정

QTE는 5초 종료 시점의 A 버튼 연타 횟수와 손님 시작 보정값을 합산한 판정값으로 판정합니다.

| 조건 | 처리 |
|---|---|
| 상인의 판정값 > 손님의 판정값 | 상인 승리. 상인은 10점을 얻고, 손님은 화내며 콘을 던집니다. 막대기에는 콘이 없어집니다. |
| 손님의 판정값 > 상인의 판정값 | 손님 승리. 손님은 콘을 부수고, 상인은 게임오버가 아니라 10점을 잃습니다. 막대기에는 콘이 없어집니다. |
| 상인의 판정값 = 손님의 판정값 | 무승부. 아무 결과 없이 일반 플레이로 복귀하며, 콘은 막대기에 그대로 붙어 있습니다. |

QTE가 진행되는 동안에는 60초 게임 타이머가 정지하며, QTE가 종료되면 기존 남은 시간부터 다시 흐릅니다.

## 8. 점수 규칙

| 점수 종류 | 획득 조건 | 획득 점수 |
|---|---|---|
| 지속 점수 | 막대기에 붙은 콘이 손님의 큰 점수 콜라이더 안에 있음 | 1초당 1점 |
| QTE 상인 승리 | 5초 A 연타 힘겨루기에서 상인의 판정값이 손님보다 많음 | +10점 |
| QTE 손님 승리 | 5초 A 연타 힘겨루기에서 손님의 판정값이 상인보다 많음 | -10점 |
| QTE 무승부 | 5초 종료 시점에 상인과 손님의 판정값이 같음 | 0점 |

콘이 많이 잡힐수록 QTE 상인 승리로 10점을 얻을 기회는 늘어납니다. 하지만 손님이 QTE에서 이기면 게임오버가 아니라 10점을 잃으므로, QTE 발생 빈도가 높을수록 점수 변동 폭이 커집니다.

준비 실패로 게임오버가 되더라도 게임오버 시점까지 획득한 점수는 해당 플레이 기록으로 저장합니다.

---

## 9. 난이도 상승 규칙

- 제한 시간이 적게 남을수록 손님의 손 이동 속도가 빨라집니다.
- 제한 시간이 적게 남을수록 손님이 콘을 추적하고 Grab 타이밍을 노리는 속도가 빨라집니다.
- QTE는 5초 A 연타 힘겨루기입니다.
- 손님이 콘을 잡아 QTE를 시작한 누적 횟수가 많아질수록 QTE 시작 지점은 손님에게 점점 유리해집니다.
- QTE가 많이 발생하면 상인은 +10점을 얻을 기회와 -10점을 잃을 위험을 동시에 더 많이 마주합니다.
- 손님에게는 추후 개별 기믹 패턴을 추가할 수 있습니다.
- 기믹 패턴은 기본 회피, 점수 획득, QTE 규칙을 해치지 않는 범위에서 확장합니다.

---

## 10. 싱글 플레이 게임오버와 게임 종료

다음 조건 중 하나를 만족하면 게임오버입니다.

- 게임 시작 후 15초 안에 아이스크림과 콘 준비를 완료하지 못한 경우

손님이 콘 주기 QTE에서 승리해도 게임오버가 아니며, 상인은 10점을 잃고 게임을 계속합니다.

60초 제한 시간이 끝날 때까지 플레이를 유지하면 게임 클리어입니다. 게임오버와 생존 종료 모두 최종 점수를 기록합니다.

---

## 11. 현재 우선 구현 범위

- 광장 스폰과 부스 게임 시작 상호작용
- 60초 게임 타이머와 15초 준비 제한
- 아이스크림 통과 콘 통을 이용한 준비 과정
- 콘 존재 여부와 추적 가능 범위에 따른 손님의 추적 모드·대기 상태 전환
- 콘 부착 시 막대기에 붙은 콘을 손님의 추적 가능 범위 안으로 자동 이동시키는 처리
- 손님의 점수 콜라이더, 손 콜라이더, 얼굴 트리거
- 1초당 1점의 지속 점수
- 싱글플레이와 멀티플레이 모두 5초 고정 제한을 사용하는 콘 주기 QTE
- 상인과 손님이 모두 A 버튼을 연타하는 힘겨루기 QTE
- 손님이 콘을 잡아 QTE를 시작한 누적 횟수
- 손님 콘 잡기 누적 횟수에 따른 QTE 시작 보정
- 5초 종료 시점의 A 연타 횟수와 시작 보정값 합산 판정
- 상인 승리 시 +10점과 손님의 콘 던지기
- 손님 승리 시 콘 파괴와 상인 -10점 처리
- 무승부 시 결과 없이 일반 플레이 복귀 및 콘 유지
- 손님의 작은 손 콜라이더와 Grab 입력 동시 조건
- 손님의 Grab 입력 0.5초 쿨타임
- 180도 회전 스킬, 기본 1초 쿨타임과 별도 회전 유지 시간
- 얼굴에 아이스크림 묻히기 스킬의 2회 제한과 감속 효과
- 남은 시간에 따른 손 속도와 Grab 타이밍 압박 상승
- QTE 발생 누적에 따른 점수 변동 기회 증가
- 준비 실패 게임오버, 생존 종료, 최종 점수 기록

---

## 12. 공통 게임 시작 방식

싱글플레이와 멀티플레이 모두 터키 아이스크림 부스에서 시작합니다.

1. 플레이어 한 명이 터키 아이스크림 부스에 들어갑니다.
2. 게임 시작 메뉴에서 싱글플레이 또는 멀티플레이를 선택합니다.
3. 싱글플레이를 선택하면 해당 플레이어가 터키 아이스크림 상인이 되어 게임을 시작합니다.
4. 멀티플레이를 선택하면 손님 대기 칸이 활성화됩니다.
5. 다른 플레이어 한 명이 손님 대기 칸에 들어가 상호작용하면 멀티플레이 참가가 확정됩니다.

---

## 13. 멀티플레이 기본 규칙

- 하나의 월드에는 여러 플레이어가 동시에 접속할 수 있습니다.
- 실제 게임은 두 명의 플레이어가 참여하는 1대1 방식으로 진행합니다.
- 게임에 참가하지 않은 플레이어는 부스 밖에서 대기하거나 진행 중인 게임을 구경할 수 있습니다.
- 참가자 두 명 중 첫 라운드의 터키 아이스크림 상인과 손님 역할은 무작위로 배정합니다.
- 첫 라운드가 끝나면 두 플레이어가 역할을 서로 바꾸어 두 번째 라운드를 진행합니다.
- 각 플레이어는 터키 아이스크림 상인 역할을 한 번씩 플레이합니다.
- 두 라운드가 끝나면 각 플레이어가 터키 아이스크림 상인 역할로 획득한 점수를 비교해 승패를 결정합니다.
- 점수가 높은 플레이어가 승리하며, 점수가 같으면 무승부입니다.

별도로 명시되지 않은 준비 시간, 플레이 제한 시간, 점수 획득 및 스킬 규칙은 싱글플레이의 터키 아이스크림 상인 규칙을 따릅니다.

### 13-1. 멀티플레이 진행 순서

1. 첫 번째 플레이어가 부스의 게임 시작 메뉴에서 멀티플레이를 선택합니다.
2. 손님 대기 칸이 활성화됩니다.
3. 두 번째 플레이어가 손님 대기 칸에 들어가 상호작용합니다.
4. 두 플레이어의 첫 라운드 역할을 무작위로 배정합니다.
5. 첫 번째 라운드를 진행하고 터키 아이스크림 상인의 점수를 기록합니다.
6. 두 플레이어의 역할을 교대합니다.
7. 두 번째 라운드를 진행하고 터키 아이스크림 상인의 점수를 기록합니다.
8. 두 점수를 비교해 승리, 패배 또는 무승부 결과를 표시합니다.

---

## 14. 멀티플레이 콘 쟁탈 QTE

멀티플레이에서 손님은 직접 콘을 잡아 터키 아이스크림 상인에게 QTE를 발생시킬 수 있습니다. QTE의 기본 시간, A 연타 힘겨루기 구조, 점수 결과는 싱글플레이 QTE와 동일합니다.

### 14-1. 시작 조건

1. 손님 플레이어가 오른손의 작은 손 콜라이더를 아이스크림에 붙은 콘 콜라이더에 닿게 합니다.
2. 콘에 닿은 상태에서 오른손 컨트롤러의 Grab 버튼을 누릅니다.
3. Grab 버튼에는 0.5초 쿨타임이 적용됩니다.
4. 조건이 충족되면 터키 아이스크림 상인 플레이어와 손님 플레이어 모두에게 A 연타 입력이 활성화됩니다.
5. 멀티플레이 콘 쟁탈 QTE의 제한 시간은 5초 고정입니다.

### 14-2. 플레이어별 입력

| 역할 | 입력과 목표 |
|---|---|
| 터키 아이스크림 상인 | 5초 동안 오른손 컨트롤러 A 버튼을 최대한 많이 연타합니다. |
| 손님 | 5초 동안 오른손 컨트롤러 A 버튼을 최대한 많이 연타합니다. |

### 14-3. 결과 판정

| 결과 | 조건 | 처리 |
|---|---|---|
| 상인 성공 | 5초 종료 시점에 상인의 판정값이 손님보다 많음 | 상인은 10점을 얻고, 손님은 화내며 콘을 던집니다. 막대기에는 콘이 없어집니다. |
| 손님 성공 | 5초 종료 시점에 손님의 판정값이 상인보다 많음 | 손님은 콘을 부수고, 상인은 게임오버가 아니라 10점을 잃습니다. 막대기에는 콘이 없어집니다. |
| 무승부 | 5초 종료 시점에 상인과 손님의 판정값이 같음 | 아무 결과 없이 QTE를 종료합니다. 콘은 막대기에 그대로 붙어 있습니다. |

멀티플레이 콘 쟁탈 QTE는 싱글플레이와 동일하게 손님 콘 잡기 누적 횟수에 따른 시작 보정값을 적용하고, 5초 종료 시점의 판정값 비교로 결과를 확정합니다.

## 15. 구현 우선순위

멀티플레이는 후순위 구현 대상으로 둡니다. 우선 싱글플레이의 전체 게임 루프, 판정, 점수, 스킬과 게임 종료가 안정적으로 동작하도록 구현한 뒤 멀티플레이를 개발합니다.

멀티플레이 구현 범위는 다음과 같습니다.

- 월드 내 다중 접속과 관전
- 멀티플레이 참가자 두 명 확정
- 첫 라운드 역할 무작위 배정과 두 번째 라운드 역할 교대
- 각 플레이어의 상인 점수 기록과 승패 판정
- 손님 플레이어의 콘 접촉 및 Grab 입력 판정
- 손님의 Grab 입력 0.5초 쿨타임
- 상인과 손님이 모두 A 버튼을 연타하는 힘겨루기 QTE
- 손님 콘 잡기 누적 횟수에 따른 QTE 시작 보정
- 5초 고정 제한과 종료 시점 판정값 비교
- 상인 승리 시 +10점, 손님 승리 시 -10점, 무승부 시 결과 없음

## 16. 기획상 핵심 문장

플레이어는 60초 동안 터키 아이스크림 상인이 되어 손님에게 콘을 쉽게 내주지 않도록 회피하고, 위험한 거리에서 점수를 쌓으며 A 연타 힘겨루기 QTE와 스킬을 활용해 최고 기록에 도전합니다.
